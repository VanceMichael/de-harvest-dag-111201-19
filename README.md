# 成果采集·可恢复动态依赖图

面向合作资料接收人员的 Python 采集组件。把“目录 → 成果修订 → 详情 → 附件”建成
可在运行中生长、可崩溃恢复的动态依赖图，节点产物、依赖、订阅与运行进度全部落 SQLite。
输入样本都是本地合成数据，example 域名只表示来源身份，默认不联网（演示用进程内脚本化客户端，
`--network` 可切换为真实回环 HTTP 来源）。

## 安装与运行

使用 Python 3.11，依赖仅为标准库，SQLite 随解释器提供，无需安装第三方包。
从项目根目录执行；`graph` 演示启动多个 worker 并发处理、事务入库后读取实际结果，
覆盖附件反复失败、304 沿用、修订替代、共享订阅取消、进程重启恢复与晚到旧产物。
每次演示使用独立临时目录，结束后清理；通常数秒内结束。

```bash
python3 -m compileall -q collector tests
python3 -m unittest discover -s tests -v
python3 -m collector graph            # 进程内脚本化来源，结果确定
python3 -m collector graph --network  # 真实回环 HTTP 来源
```

## 动态依赖图语义

节点按 URL/标识全局共享，分四类：目录 `catalog`、成果修订 `work`、详情 `detail`、附件 `asset`。

- **动态发现**：附件集合只有解析详情后才知道。详情 200 解析出新附件时即时建节点、
  加依赖边并入队；每条新边经过可达性防环检查，成环即拒绝并记审计事件。
- **304 沿用依赖**：详情返回 304 时不重新解析，沿用上次发现并已持久化的依赖边，
  绝不会被当成“没有附件”；条件请求带 `If-None-Match`。
- **修订冻结**：每个成果修订在自己的代次（gen）冻结依赖集合（边带 `frozen_gen`）。
  新修订替代旧修订后两者依赖互不影响；晚到的旧代次附件产物只留档，
  不触发新修订交付（记 `stale_product_ignored`）。
- **就绪状态对外可见**：区分 `采集中`、`核心资料不齐`（必需附件缺失/失败）、
  `可用但缺可选项`（必需齐全、仅可选缺失）、`完整`、`已取消`、`已被新修订替代`。
- **局部重试**：附件失败只重跑该节点本身并退避，成功的目录/详情/后继不重复请求；
  超过 `max_attempts` 标记失败并反映为核心资料不齐。
- **共享订阅与取消**：共享附件按订阅者计数。取消一个成果只撤它自己的订阅，
  共享节点在所有订阅者取消后才停；在途请求返回时经守卫确认，不会把已取消节点复活。
- **并发不提前交付**：节点完成、动态加边、成果交付判定共用同一把图锁串行提交，
  worker 完成节点与另一路新增依赖并发时，不可能在依赖未齐备时提前交付。
- **持久化与恢复**：节点、边、订阅、产物、请求流水、事件流水均在 SQLite。
  重建引擎即恢复；已成功附件重启后不重发，仅目录/详情在恢复时做一次条件再验证。

## 组件与数据

`graphstore.py` 定义节点/边/订阅/产物/请求/事件表与可重入事务；`engine.py` 是
单调度线程 + worker 池的并发引擎，维护就绪队列与退避重试堆；`scenario.py` 加载
`fixtures/graph.json` 编排端到端演示；`transport.py` 提供请求客户端、支持门闩与
延迟的本地回环响应服务。
旧的固定图拓扑工具仍保留在 `domain.py`（`topological`/`collect`），
原始对象与导入凭据保留在 `storage.py`，查询入口在 `api.py`。

## 持久化表

`nodes`（节点与运行状态）、`edges`（带 `frozen_gen` 的冻结依赖）、
`subscriptions`（订阅引用与取消标记）、`products`（产物及来源版本标识）、
`requests`（实际 HTTP 请求流水）、`journals`（取消/替代/晚期产物等领域事件）、
`meta`（代次计数器）。数据库路径默认在 `var/` 下，已忽略不入库。

## 可复现运行

宿主机或容器均不需要网络。镜像准备好以后可以关闭外部网络再运行上述命令。
仓库内不含真实账号、新闻正文或人员资料；不要将生产凭据写入样本或日志。
